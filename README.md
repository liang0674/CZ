# 投资全景 · 线上版

此版沿用个人本地最新版的页面和账本功能。首次打开时需要录入持仓、现金，或导入线上版 JSON 备份。账本与历史、现金流水、列设置及锁屏密码保存在当前浏览器。

## 发布到 GitHub Pages

1. 创建新仓库，仅把本目录中的 `index.html`、`.nojekyll` 和本说明提交到仓库根目录。
2. 在仓库 **Settings → Pages** 选择 **Deploy from a branch**，从默认分支的 **/ (root)** 发布。
3. 在 Pages 地址里录入或导入账本。不同网址、浏览器和设备的数据独立，可用「组合风险总览 → 账户历史与回撤」中的 JSON 导出和导入迁移。备份含真实账本，请保留在自己控制的位置。

## 录入与行情

在「持仓明细」新增资产。在「操作」中编辑证券可用现金，登记股票、基金或积存金成交。股票成交联动证券现金。可以手动保存今日快照。首个有持仓数据的快照作为基准。

默认可手动维护价格。启用一键刷新时，在「账户与行情设置」填写可信的 HTTPS 服务地址。服务需允许 Pages 网址跨域访问，接口如下：

| 接口 | 响应 |
| --- | --- |
| `GET /asset-name?code=证券代码` | `{"name":"资产名称"}` |
| `GET /market-quotes?codes=逗号分隔的证券代码` | `{"quotes":{"证券代码":{"price":1.23,"previousClose":1.20,"date":"YYYY-MM-DD","source":"行情来源"}},"errors":[]}` |

行情服务独立部署。请求只包含证券代码，不发送持仓数量、金额、成本和账本记录。`previousClose` 为上一期可比价格，缺少时该项仍可更新估值。

## 账本 AI 助手

打开网页顶部「账本 AI 助手」。首次新建或添加本机项目文件夹，填写完整路径，按页面提示在桌面 Codex 里完成一次目录验证。支持目录访问的桌面浏览器会记住连接，必要时会请求恢复授权。

此后可准备新任务，在 Codex 对话里描述要添加、更新或分析的数据。勾选快照选项时，网页会把当前持仓、现金和累计投入写入该任务对应的本机文件。返回网页后可查看分析、核对数据变更并确认入账。网页只认当前任务编号，已入账的结果不会重复执行。

项目里的账本快照与结果可能含真实数据，应与 GitHub 发布目录分开存放。
